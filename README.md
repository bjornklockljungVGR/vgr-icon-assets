# vgr-icon-assets

Intern dataresurs för VGR:s ikonkatalog. Innehåller Streamline Regular 3.0.

**Inte för direktanvändning.** Filerna fetchas av VGR:s Figma Make-baserade
ikonkatalog. Om du landat här av misstag — se [LICENSE.md](LICENSE.md).

## Filer
- `sprite.svg` — 9618 ikoner som SVG-symboler
- `icons.json` — metadata (namn, kategori, taggar) för sökning
- `library-config.json` — grundkonfiguration
